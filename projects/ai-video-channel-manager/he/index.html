// סקירת מערכת

דשבורד מרכזי לניהול והקמה של מספר ערוצי וידאו מבוססי בינה מלאכותית. משתמשים יכולים להקים ערוצים חדשים או להזניק תהליכי הפקת וידאו עבור ערוצים קיימים — הכל מתוך ממשק React אחיד וידידותי.

כל פעולה מפעילה תהליך אוטומציה מבוסס n8n דרך API המנהל את כל שרשרת ההפקה: יצירת פרומפטים מותאמים עם Gemini, ייצור הווידאו באמצעות Sora, ושלב אישור אנושי בטלגרם לפני פרסום הווידאו בערוץ היעד.

הפרויקט פותח בליווי Claude Code ככלי פיתוח מבוסס סוכני AI, המדגים שילוב מתקדם בין הנדסת Full-Stack קלאסית לפיתוח Agentic מודרני.

// הדגמת תהליך האישור

1. הטריגר

ההפקה מתחילה בדשבורד של TubeFlow. לחיצה על Generate Video שולחת Webhook ל-n8n ומפעילה את תהליך היצירה הרב-סוכני.

2. אישור אנושי (Human-in-the-Loop)

כדי להבטיח איכות מקסימלית, הפרומפט הסופי והתצוגה המקדימה של הסרטון נשלחים לבוט ב-טלגרם. המשתמש יכול לאשר או לדחות את הפרסום בלחיצה אחת, מה ששומר על אוטומציה מהירה לצד פיקוח אנושי.
