// סקירת מערכת

JobPilot הוא מרכז שליטה ופלטפורמת Full-Stack לניהול קריירה, שתוכנן במיוחד כדי לייעל ולפשט את תהליך חיפוש העבודה המודרני. המערכת משמשת כפלטפורמה מרכזית למעקב אחר מועמדויות עבודה, ניהול רשת קשרים מקצועית, ואוטומציה של משימות מורכבות כגון סריקת רשת (Web Scraping) לאיתור משרות חדשות.

נבנה בארכיטקטורת Dual-Backend מפוצלת, המשלבת שרת Node.js / Express רספונסיבי לניהול הנתונים והמשתמשים לצד שירות Python FastAPI ייעודי המניע יכולות AI מתקדמות באמצעות LangChain ו-Groq.

// מנוע ה-AI של LangGraph

התאמה אוטומטית של קורות חיים (Automated CV Tailoring)

המערכת מפעילה פייפליין AI מתקדם המבוסס על סוכני LangGraph להתאמה אוטומטית של קורות החיים לתיאור משרה ספציפי. הבינה המלאכותית מפענחת את נתוני הפרופיל או קובץ PDF שהועלה, ממפה אותם לסכמה התקנית של JSON Resume, ומייצרת בזמן אמת קובצי PDF של עמוד אחד בגודל A4 באמצעות דפדפן Headless (Puppeteer).

// הדגמת פיצ'רים
Application Tracker

Interview Insights

Analytics Dashboard

Network Edge

Auto Search

Email Auto-Status

Skills Management

רשמו את הכישורים שלכם פעם אחת – הם משמשים להתאמת קורות החיים ולחישוב התאמה לכל משרה.

Portfolio

הוסיפו את הפרויקטים שלכם – מנוע התאמת קורות החיים יבחר את המתאימים ביותר לכל משרה.

// ארכיטקטורה ופייפליין נתונים

מורכבות טכנולוגית

  • ארכיטקטורת מיקרו-סרוויסים (Dual-Backend): הפרדת תחומי האחריות בין שרת API ב-Node.js (ניהול נתוני משתמש ואימות מול Supabase) לבין שירות FastAPI ב-Python המותאם במיוחד למשימות עיבוד כבדות של AI.
  • סוכני בינה מלאכותית (Agentic AI Workflows): מימוש LangChain ו-LangGraph ליצירת סוכנים רציפים המקבלים החלטות אוטונומיות, מחלצים ישויות מקורות החיים ומשכתבים הישגים והדגשים מקצועיים בהתאמה מדויקת לדרישות המשרה.
  • פייפליין הפקת PDF דינמי: המרת עורך הטקסט העשיר (Quill) לסכמת JSON Resume מובנית וקפדנית, רינדור באמצעות תבניות SSR ב-EJS/React, וייצוא לקובץ PDF סופי באמצעות Puppeteer על גבי Chromium Headless.
