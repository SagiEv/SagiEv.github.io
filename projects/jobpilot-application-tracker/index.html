// System Overview

JobPilot is a full-stack career command center engineered to streamline the modern job search. It serves as a centralized platform for tracking job applications, managing professional networks, and automating tedious tasks like web scraping for new roles.

Built with a dual-backend architecture, it combines a highly responsive Node.js/Express API for core data management with a dedicated Python FastAPI service driving powerful AI capabilities powered by LangChain and Groq.

// LangGraph AI Engine

Automated CV Tailoring

The system uses an advanced AI pipeline utilizing LangGraph agents to automatically tailor your resume to specific job descriptions. The AI parses your profile data or uploaded PDFs, maps it into the official JSON Resume schema, and dynamically renders single-page A4 PDFs via a Puppeteer headless browser.

// Feature Highlights
Application Tracker

Log every job you apply to, update its status, and keep notes from screenings and interviews in one place.

Interview Insights

Log your interviews and generate an AI report that spots patterns – what to keep and what to improve.

Analytics Dashboard

See the numbers behind your job search – stats, conversion rates and trends over time.

Keep track of industry contacts who can help – their details, company, and a shortcut to its careers page.

Add companies you're interested in and get them checked periodically for new matching roles.

Connect your email to update application statuses automatically and get notified – never miss a reply.

List your skills once – they power CV tailoring and job-fit scoring for every application.

Portfolio

Add your projects – the CV tailoring picks the ones that best fit each role.

// Architecture & Pipeline

Technical Complexity

  • Dual-Backend Microservices: Segregated monolithic domains into a Node.js API (user data, auth via Supabase) and a FastAPI service optimized for heavy AI generation tasks.
  • Agentic AI Workflows: Implemented LangChain and LangGraph to create sequential decision-making agents capable of extracting entities from resumes and rewriting bullet points intelligently.
  • PDF Generation Pipeline: Converts Quill rich-text HTML into strict JSON Resume schemas, rendering via EJS/React SSR templates, and exported to PDF utilizing Puppeteer on a headless chromium instance.
