Shift Scheduler

// Reserve Duty Shift Management · React · Supabase · Vercel

View on GitHub React Supabase Vercel
// System Overview

Shift Scheduler is a highly specialized, responsive web application designed specifically to manage reserve duty shifts. The core problem it solves is algorithmically assigning night and day shifts while adhering to strict fairness constraints, such as ensuring no personnel is required to be awake at night more than once.

// Core Features
  • Constraint-Based Generation: Automatically generates shift lists that enforce rest periods, guaranteeing that personnel won't be assigned consecutive night shifts.
  • Continuous Fairness Tracking: Users can paste the shift list from the previous day to act as a stateful seed, ensuring rotational fairness carries over across consecutive days.
  • Dynamic Personnel Management: Toggle personnel status between "in base" and "at home", dynamically adjusting the pool of available shift workers on the fly.
  • Drag & Drop Editing: Fine-tune the automatically generated schedule with a seamless drag-and-drop interface to manually adjust shift placements.
  • Clipboard Export: Instant generation and simple one-click copy functionality to quickly share the finalized shift list across external communication channels.
