// Overview

WebMixer allows DJs to plug in affordable or professional MIDI controllers and mix music directly from active YouTube tabs in the browser. You no longer need to download MP3 files or manage heavy desktop software like Rekordbox or Serato just to jam to tracks on YouTube.

The extension injects high-precision content scripts into YouTube tabs that control playback, audio equalization, speed, and seeking in real time, all routed from physical hardware controls with zero perceptible latency.

// Key Features
  • Dual Deck Control: Route two independent YouTube tabs to Deck A and Deck B with individual gain, pitch, and playback control.
  • Full Hardware MIDI Integration: Standard Play/Pause, Cue points, Jog wheels (Scratch & Pitch Bend), Crossfader, and multi-band rotary EQs.
  • Real-Time Audio DSP: Switchable 2-band (Treble/Bass) or 3-band (Hi/Mid/Low) biquad audio equalization directly injected into the media element stream.
  • Browser Effects Pad: Apply real-time web audio effects such as Echo, Flanger, and Reverb via an interactive XY touch/mouse pad.
  • Drag-and-Drop Queue: Built-in YouTube video search panel inside the console; drag search results directly into Deck queues.
  • Background Operation: Mix, scratch, and browse tracks from your physical mixer completely in the background while other tabs or windows are in focus.
  • Modular MIDI Engine: Generic routing engine that supports virtually any MIDI controller via customizable mapping files, supplemented by an interactive MIDI Learn logger.

// Software Architecture

WebMixer was engineered around a decoupled, event-driven Chrome Extension architecture (Manifest V3) that coordinates between USB hardware, background service workers, and host page audio graphs:

// System Architecture Breakdown:
├── dj.html / dj.js → DJ Console UI: Visual decks, EQ rotary knobs, XY Pad, and queue state.
├── background.js → Central Service Worker: Maintains unified state, routes MIDI commands to active tabs.
├── midi_mappings.js → Translation Layer: Maps raw MIDI hex bytes ([0x90, 0x0B, 0x7F]) to actions ({PLAY_PAUSE, Deck A}).
└── content.js → Injected Script: Intercepts <video>, constructs Web Audio AudioContext graphs, and executes DSP.
