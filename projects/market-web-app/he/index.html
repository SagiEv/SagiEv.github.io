// סקירת מערכת

פלטפורמת מסחר אלקטרוני Full-Stack שנבנתה מקצה לקצה — החל ממשק משתמש רספונסיבי ומודרני ב-React ועד ל-REST APIs סקלאביליים ב-Spring Boot הנתמכים על ידי מודל נתונים רלציוני ב-PostgreSQL.

הפרויקט התמקד בארכיטקטורה מודולרית לתחזוקתיות ארוכת טווח, הפרדת תחומי אחריות נקייה (Separation of Concerns) בין השכבות, ועבודת צוות ממשית באמצעות תהליכי עבודה מובנים ב-GitHub.

// תכונות מרכזיות
  • קטלוג מוצרים דינמי הכולל סינונים מתקדמים, חיפוש מהיר ודפדוף (Pagination)
  • אימות משתמשים מבוסס JWT והרשאות מבוססות תפקידים (Role-Based Authorization)
  • ניהול מחזור חיי הזמנה מלא — החל מסל הקניות ועד לסיום התשלום
  • ממשק RESTful API עשיר עם פעולות CRUD מלאות עבור כלל הישויות במערכת
  • ממשק משתמש רספונסיבי בארכיטקטורת רכיבים מודולרית ב-React
