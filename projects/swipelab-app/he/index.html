// אודות SwipeLab

פרויקט גמר בהנדסת תוכנה באוניברסיטת בן-גוריון בנגב, שפותח במטרה לפתור אתגרי עולם אמיתי במחקר אקולוגי ובמדעי הנתונים.

// צוואר הבקבוק בתיוג נתונים

מחקר אקולוגי מייצר כמויות עצומות של נתונים גולמיים, אך אימון מודלי AI/ML יעילים דורש תיוג מאומת בידי אדם. כיום, תהליך זה נשען על קומץ חוקרים מומחים בלבד, מה שיוצר צוואר בקבוק חמור, איטי ויקר המגביל את התקדמות המדע.

// ארכיטקטורה של אימפקט
// האתגר

מאגר STARdbi מכיל מעל 380,000 תמונות חרקים מ-84 אתרים אקולוגיים, אך אימון מודלים דורש תיוג מסווג. תיוג ידני בידי מומחים אינו סקיילבילי, ומותיר כמויות עתק של נתונים יקרי ערך ללא שימוש.

// הפתרון שלנו

SwipeLab הופכת את צוואר הבקבוק להזדמנות. באמצעות גיימיפיקציה של תהליך התיוג, אנו מאפשרים לקהל הרחב לתרום תיוגים איכותיים בממשק החלקה (Swipe) מהיר ומהנה. חוקרים יכולים להגדיר משימות, לעקוב אחר ההתקדמות ולייצא נתונים איכותיים לאימון מודלים.

// השפעה בעולם האמיתי

דוגמה מעשית: המזיק Diaphorina citri המתפשט בפרדסי ישראל נושא את מחלת הגרינינג הקטלנית להדרים. SwipeLab מסייעת לחוקרים לעקוב אחר פתרונות ביולוגיים (כגון צרעות טפיליות מזן Tamarixia) באמצעות ניתוח מהיר ורחב היקף של תמונות שדה.

// ארכיטקטורת המערכת

הפלטפורמה מבוססת על ארכיטקטורה מונחית אירועים לניהול משימות תיוג תמונות בתפוקה גבוהה, מנגנוני אימות מאובטחים ומכניקות משחוק מקביליות.
