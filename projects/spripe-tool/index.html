// Overview

An open-source, end-to-end asset generation tool designed to streamline the process of transforming raw video references into production-ready 2D sprites.

Spripe automates the tedious aspects of sprite creation—like background removal and frame extraction—while offering a suite of built-in, Photoshop-style editing tools for fine-tuning.

// Technical Pipeline

1. Video to PNG Sequence Extraction

The process begins by ingesting a source video file. We read the video stream frame-by-frame, extracting the necessary visual data at the correct framerate. Each captured frame is then serialized and saved as a lossless PNG image, preserving the original quality.

Core Tech: OpenCV (opencv-python) and NumPy for vectorized processing.

2. Background Removal & Transparency

Each frame is passed through an AI-driven background removal model. The model analyzes the image to distinguish the primary subject from the background, creating an alpha mask. This mask is applied to the image, converting all background pixels to transparent, leaving a clean, isolated sprite ready for animation.

Core Tech: rembg (U2-Net) and Pillow (PIL).

3. Manual Editing & Photoshop-like Tools

Since automated AI removal isn't always perfect, Spripe includes a comprehensive suite of manual editing tools. The application features a custom-built GUI with a timeline for frame navigation, layering capabilities, and interactive drawing tools (brush, eraser, selection) that mimic professional software like Photoshop.

Core Tech: PyQt6 (QGraphicsScene / QGraphicsView) and Pillow (PIL).

4. Normalization and Export

The normalization process automatically detects the bounding box of the subject across all frames, crops out unnecessary transparent padding, and centers the sprite within a standardized canvas size. This guarantees that the animation will play smoothly without jittering when imported into an engine.

Core Tech: NumPy, OpenCV, and Pillow (PIL).
